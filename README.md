# Project Meademo

A First-Person experience developed in Unreal Engine 5 for both PC (Windows) and Virtual Reality (Meta Quest - 3).

## Overview

This repository contains the source code for a personal portfolio project. It is intended to demonstrate software engineering, gameplay programming, systems architecture, and VR development practices.

## Technologies

- Unreal Engine 5
- Meta Quest 3
- Blueprints

2. Run one of the provided builds to experience the project as intended:
   - Windows build
